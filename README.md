# 家長飛盤速成指南

給家長的飛盤入門網站：飛盤比賽是什麼、2026 國內賽事、飛盤與升學、飛盤對孩子的身心好處。

最重要的一件事：**誠實與責任感**。

純 HTML + CSS，透過 GitHub Pages 發布。
